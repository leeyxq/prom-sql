## 本次修改摘要

1. **卫浴干区**：增加玻璃移门，不再完全开敞。
2. **玄关鞋柜**：深度 180 → 350 mm。
3. **老二房 B**：落地玩具架改为壁挂置物，收纳柜缩小，留出活动区。
4. **餐厅**：餐桌建议可伸缩，通行净距 ≥750 mm。
5. **电视墙**：增加隔音层施工注记。
6. **阳台**：拆墙/封窗处标注须结构确认与报批。
