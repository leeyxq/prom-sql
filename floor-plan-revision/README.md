## 本次修改摘要

1. **卫浴干区**：不设门；保留原有小半边实墙。
2. **老大房 C**：暖气放到门后；床头靠北墙（北为厨房共墙，建议隔音）；不宜床头靠西窗。
3. **老二房 B**：床头靠南；**不宜靠北**（北为卫生间）；壁挂玩具 + 矮柜，留活动区。
4. **客厅**：无暖气片。
5. **玄关鞋柜**：深度 180 → 350 mm。
6. **电视墙 / 阳台**：隔音层注记；拆改须结构确认与报批。

| 房间 | 建议 | 原因 |

| 老二房 B | 不宜靠北，改靠南 | 北墙贴卫浴（马桶/淋浴噪音与潮气） |
